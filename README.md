# Steam 市场助手

Windows 中文桌面软件，用于批量上架和下架 Steam 社区市场物品。全部操作由用户选择并预览后启动，后台按顺序逐项提交。

## 1.0.3 撤单返回与结果核验修复

修正旧版把数组、空内容等撤单返回判为“Steam 返回格式无法识别”，导致第一笔停止、其余全部取消的问题。兼容处理仅用于撤单，不会放宽库存、价格查询和上架接口的返回校验。

撤单没有明确成功标记，或提交中断、超时时，软件会重新读取完整在售列表来核验。目标挂单不再在售才继续队列；若仍在售，会间隔 1.5 秒再读一次。不能读取或两次都仍在售时，标为需要人工核对并停止，不会重复提交撤单。明确的登录失效、限流或拒绝仍会按原规则处理。

“已核实不再在售”证明挂单已经消失，不能单独证明物品是撤回还是恰好已成交，物品归还和成交状态以 Steam 库存及交易记录为准。额外核验会增加部分撤单的等待时间。

## 1.0.2 批量下架兼容修复

下架不再依赖 Steam 在售页面特定的价格样式。无法明确读取的价格显示为“价格未读取”或“—”，合计不会把未知金额当成零。仍可按物品与订单编号选择并预览批量下架。

重复的电脑/手机版价格字段只有在金额完全一致时才会被采用。字段缺失、金额冲突或格式无法判断时均保留为未知，不猜测成交价。撤单请求继续严格校验订单和资产映射，价格读取失败不会放宽这些检查。

## 1.0.1 库存加载修复

修正旧版每页请求 5000 件的参数，改为与 Steam 网页一致的首次 75 件、后续每页 2000 件，并保留游标分页直到完整读取库存。库存手续费配置页的非登录、非限流错误不再阻止加载真实库存。

HTTP 400 会显示失败环节、游戏和 Context，以及经过凭据隐藏的 Steam JSON 错误说明。加载失败后不会保留可操作的旧库存。该版本通过库存接口模拟回归测试；由于没有用户的实际响应，无法确认这是否是此次错误的唯一原因。如果仍报错，请提供完整的新提示文字，无需提供密码或 Cookie。

## 直接运行

解压 Windows 便携版压缩包，打开整个文件夹中的 **SteamMarketAssistant.exe**。请保留旁边的 resources、locales 和 DLL 等运行文件。便携版自带运行环境，无需安装 Node.js。

初次打开可点右上角 **体验演示**。演示库存、价格和结果均为本机内存中的示例，退出后重置，不会连接 Steam 交易接口。真实账户是默认模式。

## 真实使用

1. 点击左下角 **登录 Steam**，在独立的 Steam 官方页面完成扫码或账号登录。软件不设置自己的密码输入框。登录成功后自动返回，也可以关闭登录窗口后返回。
2. 选择游戏，点击 **加载库存**。预设 CS2、Dota 2、TF2、Steam 社区，也可以填写其他 App ID 和 Context ID。
3. 勾选可出售物品，填写**每件卖家到手价**和数量。可通过“批量定价”统一填写；“查看行情”显示的是买家支付参考价，不会自动转换成卖家到手价。
4. 点击 **预览上架**，核对每一项、数量、币种和总额，再勾选确认并启动。真实请求间隔为 3.5 秒，单个请求最多等待 30 秒。
5. 需要下架时进入 **在售下架**，先加载当前挂单，选择订单并预览，再确认批量下架。撤单前若物品已经成交，Steam 可能拒绝撤单。
6. 在 **执行记录**查看逐项状态；可停止尚未发送的项目、导出 CSV。任务结束后会刷新库存和在售列表。

## 金额与结果

- 币种从当前 Steam 钱包自动读取；默认演示使用人民币。当前支持经校验的两位小数钱包。日元、新台币、印度卢比等按整单位显示或未确认的钱包会禁用上架，避免金额换算错误。
- 上架输入为卖家实收的**单价**，不是买家支付金额。买家金额按当前 Steam 钱包及游戏的手续费规则估算；实际以 Steam 页面为准。系统校验最小价格、价格步长、单笔上限和库存数量。
- **需确认**表示 Steam 已接受请求，但还需要在 Steam 手机应用或邮件中完成确认，不代表已经公开在售。
- **需人工核对**表示提交后没有得到明确结果。软件会停止队列且不自动重试。先打开 Steam 市场核对，再刷新后决定是否重新提交。
- 停止队列不会撤回已经发送或成功执行的请求。队列不跨重启自动恢复；记录当前保存在内存，需要留存时请导出 CSV。

## 登录与本机数据

登录窗口使用独立的 Steam 会话。会话保存在本机该应用的用户数据目录；退出账户会清除该应用保存的登录数据。Cookie、密码、验证码和 sessionid 不传给本地界面，也不包含在任务导出中。应用没有分析、广告或第三方服务器。

真实接口使用 Steam 社区网页自身的市场端点，它们不是承诺长期稳定的公开交易 API。接口结构变化、网络限制、账户市场资格和登录状态均可能阻止操作；无法明确解析时会停止并显示错误。

Steam 当前协议对市场流程及自动化作出限制，使用前请自行阅读并确认可接受相应账号风险。本软件不绕过 Steam Guard、验证码、市场限制或手机确认。

## 从源码运行或构建

需要 Windows 10/11 x64、Node.js 22.12 或更高版本及可以访问 npm、GitHub 和 Steam 的网络。

```text
npm ci
node node_modules/electron/install.js
npm test
npm start
```

也可以双击源码中的“启动开发版.cmd”。构建便携文件夹：

```text
npm run pack
```

构建输出位于 dist。Electron 固定为 45.0.0，构建工具固定为 @electron/packager 20.3.0，依赖校验记录在 package-lock.json 中。Windows 便携版尚未做商业代码签名。

## 验证范围

交付前运行金额、手续费、数量、分页、登录状态、接口响应、队列中断和本机演示往返等自动测试，并检查桌面界面操作流程。由于没有接入用户的 Steam 账号，未执行真实市场交易，无法保证每个账户或 Steam 后续页面版本的兼容性。

本软件为独立工具，与 Valve / Steam 无隶属关系。界面中的演示物品图标为程序绘制的占位图。
